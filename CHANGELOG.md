# Changelog

## 0.1.0 — 2026-10-10

First functional developer preview, independently implemented from the MNEMO specification.

- Electron/React/TypeScript desktop app with dark/light appearance, isolated preload and SQLite persistence.
- Real PowerShell terminals, tabs, split view, resizing, output search and bundled ConPTY shutdown handling.
- Versioned authorized session import with previews, redaction, append-only indexing and worker commits.
- Memory CRUD, provenance, approval/archive/merge, revisions and local extraction proposals.
- FTS5/relationship ranking, optional Ollama vectors, budgeted context bundles and contradiction warnings.
- Stored knowledge graph, evidence-backed tasks, custom instruction profiles and audit timeline.
- Optional AI adapters and official MCP client/read-only server with explicit native permissions.
- Workspace archives, restore, Markdown export, database backup and local deletion.
- Synthetic tests/benchmarks, gated Windows CI/release workflows and unsigned installer packaging.

Production review and advanced retrieval/graph/profile features remain tracked in ROADMAP.md.
